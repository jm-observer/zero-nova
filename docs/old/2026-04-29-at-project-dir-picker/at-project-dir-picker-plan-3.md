# Plan 3: 测试、回归与验收

## Plan 编号与标题
Plan 3: 测试、回归与验收

## 前置依赖
- Plan 1: Tauri 目录枚举命令与安全边界
- Plan 2: 前端 @ 弹层交互与路径插入

## 本次目标
- 建立该功能的测试清单与回归基线。
- 明确验收标准，确保不影响现有聊天输入体验。

## 涉及文件
- `deskapp/src/__tests__/...`（新增或扩展前端交互测试）
- `deskapp/src-tauri/src/commands/file.rs` 相关测试文件（如已有命令测试模块则补充）
- `deskapp/e2e/tests/chat.e2e.spec.ts`（补充端到端用例）

## 详细设计
### 1. 单元测试（前端）
覆盖点：
- `@` token 识别与替换区间计算。
- `@` token 后续输入关键字提取与过滤结果计算。
- 目录项键盘导航（上/下/回车/Esc）。
- 选择目录与选择文件的分支行为。

### 2. 后端命令测试（Tauri/Rust）
覆盖点：
- 根目录与子目录查询正确性。
- 目录穿越拦截（绝对路径、`..`）。
- 排序规则（目录优先 + 名称排序）。

### 3. E2E 测试
关键场景：
- 聊天输入框输入 `@` 弹层出现。
- 弹层出现后继续输入关键字，列表实时缩小并仅显示匹配项。
- 鼠标点击目录下钻到子目录。
- 选择文件后路径正确写入输入框。
- 输入框正常发送行为（Enter）不受影响。

### 4. 回归关注点
- 原有快捷键（Enter 发送、Shift+Enter 换行）行为保持不变。
- 输入区附件预览、语音按钮、发送按钮不被遮挡。
- 长会话页面滚动与输入区定位未退化。

### 5. 验收标准
满足以下条件即验收通过：
1. `@` 可稳定触发并展示 project dir 内容。
2. 弹层出现后，继续输入关键字可实时过滤列表且结果正确。
3. 目录可连续下钻，且可回退。
4. 选择文件后可得到正确相对路径 token。
5. 不存在 project dir 越界访问。
6. 现有聊天发送与输入体验无明显回归。

## 测试案例
### 正常路径
1. 根目录 -> 子目录 -> 文件 三步流程完整通过。
2. 根目录弹层中输入关键字可筛出目标文件并完成选择。
3. 键盘导航完成目录下钻与文件插入。

### 边界条件
1. 空目录、深层目录、多级回退。
2. 中英文/空格路径插入正确。
3. 大小写混合关键字过滤结果正确。
4. 过滤后无匹配项时显示空结果且不崩溃。

### 异常路径
1. 目录读取失败时 UI 给出错误并可恢复。
2. 非法路径请求被后端拒绝且前端不崩溃。
