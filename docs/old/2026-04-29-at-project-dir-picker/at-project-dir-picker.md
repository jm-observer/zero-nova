# @ 项目目录选择设计

## 时间
- 创建时间：2026-04-29
- 最后更新：2026-04-29

## 项目现状
- 聊天输入框当前仅支持文本输入与 Enter 发送，不支持 `@` 触发的路径选择交互。
- 前端 `deskapp/src/ui/chat-view.ts` 对输入框只绑定了发送逻辑，没有补全弹层与路径下钻状态。
- Tauri 侧已有文件读取/打开相关命令（`file_read`、`file_open`、`file_reveal`），但没有“按 project dir 列出目录项”的命令。
- 输入区样式位于 `deskapp/src/styles/main/chat.css`，目前没有文件选择弹层样式。

## 整体目标
在 DeskApp 聊天输入区实现 `@` 路径选择能力：
1. 用户输入 `@` 后弹出 project dir 根目录的文件/文件夹列表。
2. 用户选择文件夹后，继续展示该文件夹下的子项（可持续下钻）。
3. 弹层出现后，用户继续输入关键字时，列表应根据当前 token 实时过滤（目录与文件均参与过滤）。
4. 用户选择文件后，将相对路径插入输入框（如 `@src/ui/chat-view.ts`），并关闭弹层。
5. 目录访问必须限制在 project dir 范围内，避免越界路径。

## 风险与待定项
- 状态说明（2026-05-04）：该文档中“优先取 sidecar workspace 推导项目根目录”的建议已过期。`@` 选择器权威源已迁移为后端 session file tree，详见 `docs/2026-05-04-session-file-tree-authority/`。
- 风险：大目录下项目条目过多导致前端渲染卡顿，需要分页或限制首屏条目数。
- 风险：Windows 与 Unix 路径分隔符差异会影响相对路径展示和插入格式，需要统一为 `/` 展示。
- 风险：输入法组合输入（IME）与键盘上下选择可能冲突，需要在交互层做状态判断。
